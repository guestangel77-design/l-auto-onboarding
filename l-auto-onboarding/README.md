# L-Auto Onboarding

**사업자등록증·통장사본 Vision AI 인식 + 상신 전 무결성 사전 검증 기반 구매처 등록 도우미**
롯데백화점 「롯데인들 with AI」 바이브코딩(에이전트) 분야 출품작 · 광복점 영업기획팀

> ⚠️ 가상 데이터 전용 시연 도구입니다. 실제 거래처 서류·개인정보는 사용하지 않습니다.

---

## 1. 어떤 문제를 푸나요?

| 지금 (Before) | L-Auto Onboarding (After) |
|---|---|
| 신규 구매처(팝업, 문화센터 강사, F&B 행사 등) 등록 때 15개 이상 항목을 서류를 보며 **손으로 입력** → 건당 15분 이상 | 서류 2장을 올리면 AI가 항목을 읽어 **자동 입력** → 1분 이내 |
| 사업자번호·계좌·예금주가 1자리만 틀려도 준법지원팀·정산회계팀 결재에서 **반려 → 재상신 2~4일 지연** | 상신 **전에** 국세청·예금주·압류를 자동 검증 → 문제 건은 상신 전에 걸러냄 |
| 폐업·휴업 사업자, 제3자 명의 계좌를 사람이 눈으로 확인 | 국세청 공공데이터 API로 **실시간 확인** |

**사용 대상:** 영업·MD·문화센터·F&B·시설·마케팅 등 구매처를 등록하는 전 점포·전 부서 담당자

## 2. 무엇을 하나요?

1. **서류 인식** — 사업자등록증·통장사본(JPG·PNG·PDF)을 Claude Vision으로 읽어 14개 항목을 채웁니다. 틀린 값은 화면에서 바로 고칠 수 있습니다.
2. **상신 전 사전 검증 6가지**

| 검증 | 방식 | 구분 |
|---|---|---|
| 사업자번호 형식 | 국세청 검증번호 계산 (오인식 1차 차단) | 🟢 실제 작동 |
| 국세청 휴업·폐업 확인 | 공공데이터포털 국세청 API | 🟢 실제 작동 (샘플 가상 번호만 🟡 시연용) |
| 국세청 과세유형 (일반/간이/면세) | 공공데이터포털 국세청 API | 🟢 실제 작동 |
| 국세청 진위확인 (번호·대표자·개업일) | 공공데이터포털 국세청 API | 🟢 실제 작동 |
| 예금주 ↔ 상호·대표자 일치 | 이름 정규화 대조 ((주)·주식회사·띄어쓰기 차이 무시, 법인은 대표자 개인 계좌 차단) | 🟢 실제 작동 |
| 압류 DB 대조 | 가상 압류 목록(`samples/seizure_db.csv`)과 대조 | 🟡 **시연용 Mock** (준법지원팀 파일로 바꾸면 실제 작동) |

3. **최종 판정** — 🟢 상신 가능 / 🟡 주의 항목 확인 후 상신 / 🔴 상신 불가 (+ 이유)
4. **ERP 입력 도우미** — ERP 구매처 생성요청 화면 순서대로 정리하고 칸마다 [복사] 버튼 제공
   - 사업자 유형 코드 자동 변환: 법인 `01` / 개인사업자 `02`
   - 주민등록번호 칸: 대표자 생년월일 6자리 + `0000000` (주민번호 전체는 AI로 처리하지 않음)
   - 은행명 → 금융결제원 표준 은행코드 자동 변환, 우편번호는 도로명주소 API로 자동 조회
5. **결재 상신 의견 문장 자동 작성** + **ERP 입력용 엑셀 내려받기**(검증 결과 시트 포함)
6. **지표 자동 계산** — 자동 입력 항목 수, 업로드부터 판정까지 걸린 시간

## 3. 바로 체험하기 (키가 없어도 됩니다)

화면 위쪽 **[샘플1로 체험]** 또는 **[샘플2로 체험]** → **[AI로 자동 추출하고 검증하기]**

| 샘플 | 내용 | 기대 결과 |
|---|---|---|
| 샘플1 (가나다푸드) | 정상 법인, 예금주=법인명, 주소: 롯데백화점 광복점 | 6개 검증 모두 통과 → **🟢 상신 가능** |
| 샘플2 (라마바 스튜디오) | 예금주가 제3자(이다름), 압류 등록 업체 | 예금주 불일치 + 압류 등록으로 **🔴 상신 불가** |

- Claude API 키가 없으면 🟡 **시연 모드**로 동작합니다. 샘플 서류에 한해 미리 정리한 인식 결과를 쓰고, 검증·ERP 도우미·엑셀은 똑같이 작동합니다.
- 샘플 사업자번호는 가상 번호라 실제 국세청에는 없습니다. 그래서 **샘플 번호일 때만** 국세청 3개 항목에 🟡 시연용 결과를 보여줍니다. 다른 번호를 입력하고 **[검증 다시 실행]**을 누르면 실제 국세청 API로 조회합니다.
- 우편번호는 샘플 주소(부산 중구 중앙대로 2)로 실제 도로명주소 API를 조회합니다.

## 4. 내 PC에서 실행하기

**준비:** Python 3.10 이상 (설치할 때 「Add python.exe to PATH」 체크)

**방법 A (Windows 원클릭):** `run.bat` 더블클릭

**방법 B (명령어):**
```
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
브라우저가 자동으로 열립니다 (http://localhost:8501). 끝낼 때는 검은 창에서 `Ctrl + C`.

**API 키 넣기 (선택):** `.env.example`을 복사해 이름을 `.env`로 바꾸고 키를 붙여넣습니다.

| 키 이름 | 용도 | 발급처 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 서류 인식 (Claude Vision) | console.anthropic.com |
| `NTS_API_KEY` | 국세청 상태조회·진위확인 | data.go.kr → 「국세청_사업자등록정보 진위확인 및 상태조회 서비스」 |
| `JUSO_API_KEY` | 우편번호 자동 조회 | business.juso.go.kr → 도로명주소 검색 API |

## 5. 온라인 배포 (Streamlit Community Cloud)

1. 이 폴더를 GitHub 저장소에 올립니다 (`.env`는 `.gitignore`로 자동 제외)
2. share.streamlit.io → Create app → 저장소와 `app.py` 선택 → Advanced settings에서 Python 3.12 선택
3. **Secrets** 칸에 키를 넣습니다 (코드·GitHub에는 넣지 않음)
   ```
   ANTHROPIC_API_KEY = "sk-ant-..."
   NTS_API_KEY = "..."
   JUSO_API_KEY = "..."
   ```
4. 배포 후 앱 설정 **Sharing → Public** 으로 바꿔 누구나 열 수 있게 합니다

## 7. 보안 설계

- API 키는 코드에 쓰지 않고 `.env`(내 PC) 또는 호스팅 Secrets에만 둡니다. 화면(브라우저)으로 내려보내지 않습니다.
- 올린 서류는 저장하지 않고 로그에도 남기지 않습니다. 새로고침하면 사라집니다.
- 외부로 보내는 정보 최소화: Claude에는 서류 이미지만, 국세청에는 사업자번호·개업일·대표자명만, 주소 API에는 도로명 주소만 보냅니다. **계좌번호는 검증 서버로도 보내지 않습니다.**
- 계좌번호는 화면에서 가려 보여줍니다 ([복사]는 전체 번호).
- 주민등록번호는 AI 처리 대상에서 의도적으로 제외했습니다 (생년월일 6자리만 사용).
- 공개 URL 비용 보호: 한 번 접속에 AI 인식은 20회까지.
- ⚠️ 실제 업무 적용 전, 외부 AI API로 서류를 보내도 되는지 정보보호 담당 확인이 필요합니다.

## 8. 향후 과제

- 준법지원팀 압류 DB 실제 연동 (지금은 파일 경로만 바꾸면 되는 구조: `SEIZURE_DB_PATH`)
- ERP·전자결재 자동 입력/상신 연동 (사내 플랫폼 준비 후)
- 사업자등록이 없는 프리랜서 강사 처리
- 기존 구매처 휴·폐업 정기 재조회 알림
